# Gilded Rose 요구사항 명세

**Gilded Rose**는 상점의 아이템(Item)들을 관리하고, 하루가 지날 때마다 각 아이템의 품질(가격)을 업데이트하는 시스템입니다.

품질(가격)이 변하는 방식은 아이템마다 다릅니다. 대부분의 아이템은 시간이 지날수록 가격이 떨어지지만, 어떤 아이템은 오히려 오르거나 전혀 변하지 않기도 합니다.

## 시스템 소개

### 아이템 속성

| 속성 | 의미 |
|---|---|
| `Name` | 아이템 이름. 이름에 따라 품질 변화 규칙이 정해집니다. |
| `SellIn` | 유통기한 (남은 일수) |
| `Quality` | 아이템의 품질(가격) |

### 공통 규칙

| 항목 | 규칙 |
|---|---|
| 업데이트 시점 | 하루가 지날 때마다 `updateQuality()`가 모든 아이템을 한 번씩 업데이트합니다. |
| `SellIn` 변화 | 매일 *1* 씩 감소합니다. (`Sulfuras` 제외) |
| 유통기한 경과 | 업데이트 후 `SellIn`이 *0* 미만이 되면 유통기한이 지난 것으로 봅니다. |
| `Quality` 최솟값 | *0* — 음수가 되지 않습니다. |
| `Quality` 최댓값 | *50* — 50을 초과할 수 없습니다. (`Sulfuras` 제외) |

### 아이템별 `Quality` 변화 (하루 기준)

| 아이템 | 유통기한 전 | 유통기한 후 | 비고 |
|---|---|---|---|
| 일반 아이템 | *-1* | *-2* | 유통기한이 지나면 2배 속도로 떨어집니다. |
| **Aged Brie** (오래된 브리치즈) | *+1* | *+2* | 시간이 지날수록 오히려 올라갑니다. |
| **Backstage passes** (백스테이지 입장권) | `SellIn` 11일 이상: *+1*<br>`SellIn` 10일 이하: *+2*<br>`SellIn` 5일 이하: *+3* | *0* 으로 떨어짐 | 콘서트가 가까워질수록 빠르게 오르다가, 콘서트가 끝나면 가치가 없어집니다. |
| **Sulfuras** (전설의 아이템) | 변화 없음 | 변화 없음 | `Quality`는 항상 *80* 으로 고정되며(50 상한 예외), `SellIn`도 변하지 않습니다. |
